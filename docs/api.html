trait Model

struct ByteBpe

A byte-level byte-pair encoder: text is cut into words, each word is taken as UTF-8 bytes, and the merge table turns those bytes into tokens. Every byte has a token of its own, which is what makes the encoding total: any text, valid or not, has an encoding of at least one token per byte.

cache

Remember the tokens of the words already seen. A tokenizer sees the same words over and over, so the table pays for itself on the second occurrence, and it never changes a result.

pub fn Normalizer::strips_leading_marker(Self) -> Bool

Whether a word-break marker at the very front of the text stands for a space the text does not have, rather than one it does. A model that adds a leading space puts a marker there on the way in, and taking it off again on the way out is what makes the round trip exact. A model that also drops runs of whitespace keeps taking them off until the text has a character in it, because everything it saw at the front was whitespace it meant to discard.
